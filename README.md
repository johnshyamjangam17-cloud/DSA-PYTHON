## 🧠 Key Concepts & Implementations

The laboratory exercises cover the following concepts:

| Data Structure / Algorithm | Implementations |
|---|---|
| Arrays | Basic operations and manipulation |
| Searching | Linear Search, Binary Search |
| Sorting | Fundamental sorting techniques |
| Linked Lists | Singly, Doubly and Circular Linked Lists |
| Stacks | Push, Pop, Peek and Display |
| Queues | Enqueue, Dequeue and Display |
| Binary Trees | Array-based implementation and traversals |
| Binary Search Trees | Insertion, Deletion and Searching |
| AVL Trees | Insertion, Deletion and Rotations |
| Hashing | Separate Chaining, Linear Probing and Quadratic Probing |

## 🚀 Running the Programs

To access this repository locally:

**Step 1: Clone the repository**

```bash
git clone https://github.com/johnshyamjangam17-cloud/DSA-PYTHON.git
```

**Step 2: Navigate to the directory**

```bash
cd DSA-PYTHON
```

**Step 3: Execute a Python program**

```bash
python filename.py
```

Replace `filename.py` with the required Python program.
